Discussion.
We operate entirely in symbol space: no model embeddings. Observations live on a factor graph with:

3) The decision tree (when to use what)
Start with symbol streams + factor graph + CRT lanes + Singer pilots
|
+--> (A) Estimate moments/cumulants on sliding windows & across lanes
|     - If |κ4| (and/or cross-cumulants) >> noise baseline:
|         --> Use cumulant-based alignment/unmixing (ICA-like updates).
|             Do NOT invoke matching yet. Go to (E) stopping tests.
|     - Else:
|         --> Residual ambiguity likely combinatorial -> go to (B).
|
+--> (B) Inspect local matching subgraphs (per window/lane-block)
|     - If planar / near-planar: use Pfaffian (determinant) for exact counts.
|     - Else if block-structured / small treewidth: do tree DP.
|     - Else keep k small (k ≤ 12…20) and compute local permanents exactly;
|         otherwise: approximate (Sinkhorn+Bethe, or MCMC) and continue.
|
+--> (C) Update beliefs in log-domain (sum-product)
|     - Use matrix determinant lemma for fast log-det updates in Gaussianized sub-factors.
|     - Use ∂per/∂a_ij = per(A^{(i|j)}) as exact matching messages when k is small.
|
+--> (D) Re-gate with cumulants
|     - After a matching step, recompute cumulants; if they "pop", back off combinatorics.
|     - Alternate (A)-(B) until either cumulant criteria or matching criteria stabilize.
|
+--> (E) Stopping / confidence
      - Upper bound with union bound; lower bound with Fano.
      - If bounds squeeze target error, stop; else expand window or increase k only locally.
Heuristic map.

“Low‑permanent / high‑cumulant” manifold: strong non‑Gaussian signatures → lean on cumulants; matching only in sparse tie regions.

“Low‑Pfaffian / high‑determinant” manifold: interactions are pairwise/planar or Gaussianized → use Pfaffian/determinant and log‑det to score/stop.

5) Sequencing the symbol‑only inference (pseudo‑code)
Inputs: factor graph G, CRT moduli {m_ℓ}, Singer pilots P, windows W

Precompute:
  - CRT projections: t ↦ (t mod m_ℓ)  for lane alignment (carry-free).
  - Pilot masks from Singer set (low-coherence anchoring).

For each window w ∈ W:
  1) Cumulant pass:
     - Estimate κ2, κ4 (and selected cross-cumulants) per lane and across lanes.
     - If |κ4| above threshold τ (non-Gaussian “pops”):
          Update lane alignment/unmixing (ICA-style or cumulant regression).
          Go to Step 4 (stopping).
  2) Local matching graph extraction:
     - Build bipartite subgraph B_w (positions ↔ observations) using pilot gates.
     - If B_w planar → call Pfaffian; else if small treewidth → tree DP.
     - Else:
         If k:=|B_w| ≤ k_max (e.g., 12–20): exact Ryser/Glynn permanent(s).
         Else: Sinkhorn normalize → Bethe/JSV-style approximation.
     - Convert ∂per/∂a_ij (=per-minors) into messages on edges (i,j).
  3) Sum-product step:
     - Fuse matching messages with pilot/spectral factors in log domain.
     - Use matrix-determinant lemma to update any Gaussianized sub-factors.
  4) Stopping checks:
     - Union bound upper estimate on symbol error for w.
     - Estimate H(X|Y) (from posteriors) → Fano lower bound.
     - If both bounds accept target, commit decisions in w; else enlarge w or increase k locally.
  5) Alternate:
     - Recompute cumulants on the residual; if now strong, skip matching in next iteration.

7) How the pieces support “additive‑domain” symbol inference
CRT lanes give carry‑free arithmetic and per‑lane decoupling.

Singer pilots supply low‑coherence anchors in both position and spectrum.

Cumulants leverage finite‑alphabet non‑Gaussianity to align and separate without embeddings.

Local permanents / Pfaffians settle the few remaining combinatorial ties, exactly, inside small windows.

Log‑det quantifies geometric information gain and gives fast, stable updates via the determinant lemma.

Union bound & Fano supply outer/inner handles on error to decide when to stop—or when to widen the window/increase 
k
k.

Rule of thumb: push as much as possible into cumulants and log‑det (cheap, additive). Spend exponential time only locally and only when ambiguity metrics (e.g., low Sinkhorn‑permanent, flat posterior) say you must.
