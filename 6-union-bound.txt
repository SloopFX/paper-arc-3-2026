6) Factor graphs, Bethe free energy, and “second‑order” counting

Bottom line
The union bound is a first‑order device that drops interactions; submodularity is the structure telling you how interactions (overlaps) diminish returns.

Cumulants and Bethe‑type free energies formalize “how far beyond first order” you go.

Determinant/log‑det (and Pfaffians/hafnians/permanents) encode the combinatorics of independence vs. correlation (fermionic vs. bosonic) and predict whether first‑order approximations will be benign or wildly loose.

Whitening/sphering exposes the independent degrees of freedom (bits per eigenmode); expanders and RIP designs actively create this independence.

That’s the shared skeleton across linear algebra, information theory, compressed sensing, graph theory (zig‑zag expanders, bounded treewidth), factor graphs/Bethe, numerical precision and conditioning, quantum, and lattices.

7) Pseudocode (symbol‑only, windowed)
Inputs: token stream S, window size W, CRT moduli {m_1,...,m_r}, k_max, cumulant order R, error ε.

1. Windowed whitening + pilots:
   - Apply SRHT/FJLT to each window; insert/recognize pilot patterns for calibration.
   - Estimate Σ (second order); set D from task needs.

2. Gaussian core:
   - R_G = 0.5 * log det(Σ D^{-1}).
   - Build nested lattice (Λ_f ⊂ Λ_c) aligned to windowed modes (CRT lanes).

3. Cumulant pass:
   - Estimate standardized cumulants up to order R in each window.
   - J_struct = sum of (1/12)γ_3^2 + (1/48)κ_4^2 + local cross-cumulants^2.
   - Mark pockets P where synergy statistic (e.g., O-information > τ) is positive.

4. Matching pass (local):
   - For each pocket P:
       if |P| ≤ k_max: δ_P = β log2( per/haf/pf(A_P)/per/haf/pf(A_P^null) )
       else: δ_P = certified-approx bound (Bethe/loop).
   - Δ_match = sum_P δ_P.

5. Provision & certify:
   - R_star = R_G - J_struct + Δ_match + margin(ε).
   - If capacity ≥ R_star: accept. Else: enlarge W or k_max, or loosen D/ε.

Outputs: R_star, pockets P, per-window lattice digits, guarantees (Fano + union bound).
