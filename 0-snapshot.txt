Lane A — In the weeds (how it works)
0) Simplifying assumptions you set
Everything is a channel. Decoder = random field. We don’t ask it to “explain,” we encode to survive it.

Runtime is in Hz. Think tokens/sec; memory is a budget, not a promise.

Cost is relative. Normalize to $1; models are cost× of that baseline.

1) Snapshot Envelope (prefix-free)
A tiny, machine-first header that wraps any state we inject:

<SNAP v=1 | view=monitor | res=med | reason=abstr | budget={hz:0.7, costx:0.2} | id=84 | tags=billing,bug-84>
…summary / deltas / links…
</SNAP>
Why: length-/sentinel-prefix makes it concatenable and stream-safe (prefix-free). It’s the “codec,” not the summary.

2) Pilot tones (anchors the decoder)
Embed stable, repeated markers the model can lock onto in position and spectrum:

Positional: lightweight tags like N1, V1, T84 (nouns/verbs/thread id).

Spectral: a tiny, fixed grammar for headers/keys (e.g., SNAP|view|res|reason|budget|id|tags).

Redundant copies: minimal repeats across layers (permanent/minors) for error-correction.

Readable trick: keep prose clean and append tags—humans skim, model locks:

The quick brown fox jumped over the lazy dog. ⌁ {N1:fox}{V1:jumped}{N2:dog}{T:84}

3) Multi-resolution views (your Panorama/Monitor/Common)
Common: ~100–200t, portable identity + tasks-in-flight.

Monitor: ~200–600t, active threads + next actions.

Panorama: up to budget, whole story + citations.
The Dial picks which view to emit right now under (Hz, cost×).

4) Variational selection (what goes in)
Pick deltas that move beliefs the most:

Score candidates with a cheap KL-proxy (e.g., surprisal/change vs last snapshot, TF-IDF delta, retriever logits).

Orthogonalize by thread (“diagonalize”): bucket updates to reduce crosstalk; link with sparse cross-refs (expander-ish).

5) Phase estimator (how much to send)
Maintain a tiny phase entropy gauge:

Inputs: token-level surprises, refusal/redo hints, tool outcomes.

Output: adjust patch size ±Δ (e.g., 128±32 tokens) and redundancy level.
If phase is “slipping,” bump redundancy (more pilot tones / second copy of key facts).

6) Dirty-paper prompting (cheap power boost)
If user context has known “interference” (style constraints, prior mistakes), encode a brief pre-equalizer in the header (what to ignore/fix). This is your nod to interference-aware coding without paying recap costs.

7) Hiding the code (UX)
In your UI: style headers as chips/badges; collapse by default.

In others’ UIs: append-only metadata (emoji/letters) that reads like footnotes; no readability tax.
