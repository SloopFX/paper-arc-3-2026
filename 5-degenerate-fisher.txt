13) “Low‑permanent / high‑cumulant” vs “low‑FI / high‑det” manifolds

15) FAQ‑style clarifications
“Imminent” vs “immanant”: the matrix generalization you want is immanant (ends in “‑ant”), which interpolates between determinant and permanent via group characters.

“Local permanents” are practical only on tiny blocks; treat them as diagnostics or tie‑breakers, not as your main objective.

Cumulants vs moments: use cumulants after whitening to expose independence/non‑Gaussianity; moments alone conflate effects across orders.

When do I abandon BIC? As soon as smallest Hessian/FIM eigenvalues get numerically tiny or you observe multi‑modal, flat ridges → switch to WBIC/WAIC (singular‑robust).

Pilots & Singer sets: pick pilots with near‑constant magnitude cross‑correlation; they shrink local permanents and stabilize BP.

16) Minimal pseudocode (skeleton)
INPUT: symbol sequences (L CRT lanes), pilot schedules, candidate model family

1. Lane-wise stats:
   for ℓ in 1..L:
       compute counts/moments, Σℓ, cumulants κ3, κ4, coherence μℓ

2. Curvature check:
   fit baseline → H
   if λ_min(H) > τ: score by Laplace/BIC and stop if decisive

3. Singular mode:
   run MCMC or tempered posterior with β=1/log n
   compute WBIC, WAIC for model comparison

4. Non-Gaussian check:
   whiten; if |κ4| large → ICA/cumulant contrasts for separation

5. Ambiguity blocks:
   build small confusion matrices A_k
   if needed, compute perm(A_k) or Bethe-perm
   if ambiguous → strengthen positional/spectral pilots

6. Factor-graph BP with pilot factors
   monitor Bethe free energy; iterate pilot tuning

7. CRT recombination
   estimate per-lane error pℓ; union bound for end-to-end

8. Fano check
   if I << log M → increase pilots / reduce hypothesis set
Bottom line
Use Gaussian curvature + log‑det where the model is regular.

Use RLCT/WBIC/WAIC where it isn’t.

Use cumulants to exploit non‑Gaussianity (after whitening).

Use (local) permanents / immanants / hafnians only where combinatorial ambiguity is the actual obstacle—and keep those blocks small (or Bethe‑approximate them in a factor graph).

Engineer positional & spectral pilots (Singer‑style) and CRT lanes to enforce incoherence, keep ambiguity local, and make the union bound favorable.

Always sanity‑check feasibility with Fano.
