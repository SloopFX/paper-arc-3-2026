# Hypertokens

Explicit context coordinates for reliable operator-specific language-model work.

- `vCORE.md` — paper draft.
- `vNOTES.md` — unresolved decisions and future-paper material.
- `vOUTLINE.csv` — seven-column one-screen paper map.
- `vWIKI.md` — background identities and technical reference notes.
- `README.md` — repository map.

Code and evidence: `src/` `tests/` `experiments/`. Sources: `refs/`. Raw provenance: `archive/transcripts/`.

Run `bash scripts/verify.sh` for repository sanity checks. Passing does not establish model efficacy.

Paper prose goes in `vCORE.md`; unresolved or deferred material goes in `vNOTES.md`; background reference material goes in `vWIKI.md`; structural changes also update `vOUTLINE.csv`.
